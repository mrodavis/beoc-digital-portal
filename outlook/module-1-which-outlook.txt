Which Outlook Are You Using?

Module 1: Getting Started with Outlook

Outlook comes in several versions that open the same mailbox. Learn to tell new Outlook for Windows, classic Outlook, Outlook on the web and the mobile app apart, and why this course teaches new Outlook first.

By the end of this lesson you can:
- Name the versions of Outlook you will meet at work and at school: new Outlook for Windows, classic Outlook, Outlook on the web, and the Outlook mobile app
- Tell new Outlook from classic Outlook in a few seconds by looking for the Settings button and the File tab
- Explain why this course teaches new Outlook first and when you still need the classic Outlook steps
- Describe the Microsoft Office Specialist (MOS) exam that currently covers Outlook


## Same mailbox, different windows
 type: scenario
 role: You are the new front desk coordinator at Lakeside Medical Associates.
 text: On your first morning, Denise Carter, the office manager, emails you the front desk training binder. Every screenshot in it shows a File tab. Your desk computer shows no File tab at all, just Home, View and Help, and a switch at the top that says New Outlook. That evening you check the same mailbox in a web browser at home, and it looks almost like your desk computer. Same messages, three different windows.
 task: Figure out which Outlook you are looking at, so you know which set of instructions to follow.

Outlook is not one program. When your employer or school uses Microsoft 365, your mail, calendar and contacts live in your organization's mailbox on Microsoft's servers. Each version of Outlook is a different window onto that same mailbox. A message you file in a folder on your desk computer is already in that folder when you open Outlook on your phone, because you moved it on the server, not on the computer.

    Outlook mobile

Note: Microsoft built new Outlook for Windows from Outlook on the web. The two share the same layout, the same Settings pages and most of the same features. If you learn one, you can use the other.


## How to tell which one you have
Microsoft's own test is simple. Look at the top right corner of the window. If you see a Settings button, the gear icon, you have the new Outlook. If the Settings button is missing, you are in classic Outlook. The Ribbon gives you a second clue: new Outlook shows the tabs Home, View and Help, and classic Outlook has a File tab at the left end of the Ribbon.

 type: table
 caption: Where to find version details
 columns:
   In this version
   Go to
 rows:
    New Outlook for Windows
    Settings › General › About Outlook
    Classic Outlook
    File › Office Account (or File › Help on some installations)

 type: worked-example
 title: Helping a coworker over the phone
 task: Omar calls from the back office: "Denise told me to change my signature, but I can't find File › Options." Work out which Outlook he has before giving directions.
 steps:
   move: Ask him to look at the top right corner of the Outlook window and tell you whether there is a gear icon.
   why: The gear is the quickest test Microsoft gives. It does not depend on window size or on which tab is open.
   move: He says yes, there is a gear, and the tabs say Home, View and Help.
   why: Two clues agree: that is new Outlook. File › Options is a classic Outlook path, which is why he can't find it.
   move: Give him the new Outlook path: Settings › Accounts › Signatures.
   why: Directions only help if they match the version on the screen. Most confusion with Outlook help articles comes from following classic steps in new Outlook, or the other way around.
 result: Omar finds the Signatures page in under a minute.
 takeaway: Before you give or follow Outlook directions, check for the Settings gear. It tells you which set of steps applies.

Practice: Sort each clue into the version of Outlook it points to.


## Why this course teaches new Outlook first
Microsoft is moving organizations from classic Outlook to new Outlook in stages. Recent versions of Windows 11 already include the new Outlook app. For large organizations, Microsoft has announced that new Outlook will be turned on by default starting in March 2027, and people will still be able to switch back to classic Outlook during that stage. Microsoft has also said it will keep supporting classic Outlook until at least 2029, so you will see both versions at work for years. New Outlook is where Microsoft adds new features, and it matches Outlook on the web, which many schools and clinics give staff and students in a browser.

- Every lesson teaches the new Outlook steps first. The practice simulations are copies of the new Outlook window.
- Where classic Outlook works differently, you will see a Classic Outlook note with the classic steps, so you can follow along on either version.
- Some features exist in only one version. For example, Undo send and Sweep are new Outlook features, while AutoArchive is classic Outlook only. The lessons point these out.

Note: Classic Outlook: if your computer shows a File tab, you are using classic Outlook. The ideas in this course are the same. Look for the Classic Outlook notes for the click paths that differ, such as File › Options, File › Automatic Replies and Home › Rules.

 type: key-terms
 terms:
   term: Mailbox
   definition: Your organization's copy of your mail, calendar, contacts and tasks, stored on the mail server. Every Outlook app shows the same mailbox.
   term: Work or school account
   definition: The Microsoft 365 account your employer or school gives you. Shared mailboxes, Teams meetings and encryption need one.
   term: New Outlook for Windows
   definition: The current Outlook app for Windows, built from Outlook on the web. It has a Settings button and no File tab.
   term: Classic Outlook
   definition: The long-standing desktop Outlook with a File tab. Still supported and still common in offices.
   term: Outlook on the web
   definition: Outlook in a web browser. Nearly identical to new Outlook for Windows.


## Certification: the MOS Outlook exam
Microsoft Office Specialist (MOS) certifications are run by Certiport. The Microsoft 365 Apps series of MOS exams covers Word, Excel and PowerPoint, but it has no Outlook exam. The Outlook exam Certiport currently lists is Outlook Associate (Office 2019), exam MO-400, and Microsoft's exam page shows no retirement date for it.

Note: MO-400 is based on classic Outlook 2019, not new Outlook. If you plan to take it, practice the classic Outlook steps in the Classic Outlook notes, and check Certiport's current exam list before you register, because exams are added and retired over time.


## Knowledge Check
Check yourself: A coworker's Outlook window has a File tab at the left end of the Ribbon and no gear icon at the top right. Which Outlook is it? Answer: Classic Outlook. A File tab and no Settings button are the signs of classic Outlook. New Outlook and Outlook on the web have a Settings gear and no File tab.

Check yourself: Why can you follow most of this course in Outlook on the web as well as in new Outlook for Windows? Answer: New Outlook for Windows was built from Outlook on the web, so they share the same layout and settings. Microsoft built new Outlook for Windows from Outlook on the web. The Settings pages, Ribbon tabs and most features match.

Check yourself: Which Microsoft Office Specialist exam currently covers Outlook? Answer: Outlook Associate (Office 2019), exam MO-400. Certiport lists Outlook Associate (Office 2019), exam MO-400. The Microsoft 365 Apps series has no Outlook exam.
