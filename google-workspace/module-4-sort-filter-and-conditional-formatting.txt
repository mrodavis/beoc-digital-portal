Sorting, Filtering, and Conditional Formatting

Module 4: Google Sheets

Sort a range, filter rows, save a filter view that only changes your view, highlight what matters with conditional formatting, and turn a list into a table.

By the end of this lesson you can:
- Sort a range with a header row using Data › Sort range
- Filter rows with Data › Create a filter
- Create and save a filter view that does not change what others see
- Highlight cells with conditional formatting rules
- Convert a range to a table with Format › Convert to table


## Sorting

 type: scenario
 role: You keep the maintenance request log with Kim.
 text: The log has dozens of requests from both buildings. Kim wants the requests grouped by building Denise wants to see only what is still open Marcus wants his own Riverside view without changing anyone else's and the high-priority requests should stand out at a glance.
 task: Sort filter and highlight the log for each person's needs.


1. Select the data, including the header row.
2. Data › Sort range › Advanced range sorting options.
3. Check Data has header row, choose the column to sort by, and choose A to Z or Z to A. Add another sort column for a second level.
4. Click Sort.

Note: Select every column of the data before you sort. If you sort only one column, it no longer lines up with the rest of its row, and the log is scrambled. If that happens, press Ctrl+Z right away.


## Filters and filter views
- Filter: select the data and choose Data › Create a filter (or right-click › Create a filter). Click the filter button in a header to filter by values, by condition, or by color. Data › Remove filter turns it off.
- A filter changes the sheet for everyone who has it open, and anyone who can edit can change it.
- Filter view: Data › Create filter view. Filter or sort, then click Save view at the top right, name it, and click Save. It changes only your view, so several people can use different views at the same time.
- Find saved views later with Data › Change view.

Practice: Sort each situation.


## Conditional formatting and tables
1. Select the cells, then Format › Conditional formatting. The Conditional format rules panel opens on the right.
2. Under Format cells if…, choose a condition, such as Text is exactly, Greater than, or Is empty, and type the value.
3. Under Formatting style, choose how matching cells look.
4. Click Done. The rule keeps working as data changes.

A table turns a range into a structured list: select the data and choose Format › Convert to table. The table gets a header style and a name, and you can set a type for each column (such as number, date, dropdown, or checkbox) so entries that do not fit are flagged.

## Knowledge Check
Check yourself: Kim and Marcus are both in the log. Marcus wants to see only Riverside rows without changing Kim's screen. What should he use? Answer: Data › Create filter view. A filter view changes only Marcus's view.

Check yourself: You want every High priority cell to turn red automatically, now and when new requests are added. What do you use? Answer: A conditional formatting rule. A conditional formatting rule checks the cells for you and keeps working as data changes.
