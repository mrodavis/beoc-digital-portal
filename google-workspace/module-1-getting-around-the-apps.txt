Getting Around Drive, Docs, Sheets, and Slides

Module 1: Getting Started with Google Workspace

Move between the Google apps, start a new file from a blank page or a template, and learn the parts of the screen that every Google editor shares.

By the end of this lesson you can:
- Open Docs, Sheets, and Slides from the Google apps menu and from their home screens
- Start a new file from a blank page or a template, and give it a clear name
- Name the parts of a Google editor: title, menus, toolbar, document status, version history, comments, and Share
- Find any command with Search the menus (Alt+/)


## Moving between apps

 type: scenario
 role: You are setting up your first files at Parkview Property Management.
 text: Denise asks you to start a letter to a vendor and a supply order spreadsheet. You know Word and Excel but the Google apps are new and you want to stop guessing where things are.
 task: Open the right app start each file from a blank page or a template name it and find commands quickly.


- The Google apps menu is the grid of dots at the top right of Drive, Gmail, and the app home screens. Click it, then click an app. The order of the apps is set by Google; you cannot rearrange them.
- Each app also has its own address: docs.google.com, sheets.google.com, slides.google.com, drive.google.com, mail.google.com, calendar.google.com.
- In an open document, click the Docs (or Sheets or Slides) logo at the top left to go back to that app's home screen.
- Every file opens in its own browser tab, so you can keep Drive in one tab and your document in another.


## Home screens and templates
Docs, Sheets, and Slides each open to a home screen. Across the top is Start a new document (or spreadsheet, or presentation) with a Blank option and a few templates. Template gallery at the top right shows more. Below that is a list of your recent files.


 type: table

 columns: 
  From
  How
  Same as in Microsoft Office

   File › New in Word or Excel

   Inside Docs

   File › New in Word


Note: A file you start from a home screen is saved in My Drive. A file you start with New in a Drive folder is saved in that folder. Either way, you can move it later.

A new file is named Untitled document (or Untitled spreadsheet). Rename it right away so you and your coworkers can find it: click the name at the top left, type a clear name such as Parkview Supply Order, and press Enter.

## Find any command
Can't find a command? Click Search the menus (the magnifying glass at the left end of the toolbar) or press Alt+/ and type what you want, like word count or page setup. Press Enter to run the first match. Ctrl+/ shows the keyboard shortcuts.

Ctrl+S does nothing harmful in Google's editors, but you never need it. Look for Saved to Drive by the document status icon if you want to be sure.


## Knowledge Check
Check yourself: You started a document from the Docs home screen and it is called Untitled document. What is the fastest way to rename it? Answer: Click the name at the top left, type the new name, press Enter. The file name at the top left is a box you can click and type in. The new name is saved right away.

Check yourself: You need Page setup but cannot find it. What is the quickest way? Answer: Press Alt+/ and type page setup. Search the menus (Alt+/) finds any command by name.
