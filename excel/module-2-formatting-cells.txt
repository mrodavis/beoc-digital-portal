## Formatting should help someone read the numbers
 type: scenario
 role: You prepare the monthly budget review at Lakeside Medical Associates.
 text: You shade the over-budget rows red. The report is printed in black and white for the board meeting, where every row is now identical gray. The one thing the report existed to communicate is invisible.
 task: Format so the meaning survives printing, photocopying, and colorblind readers.

The rule is that color may reinforce meaning but must never be the only thing carrying it. Add a status column reading 'Over budget,' or a symbol, or bold. Then the red shading is a helpful accent rather than the sole signal — and the report still works in greyscale.

Cell Styles (Home > Cell Styles) are Excel's equivalent of Word's styles: named formatting you apply by reference. Using the built-in Heading, Total, and Input styles means a workbook stays consistent, and restyling it later is one change rather than a hunt through every sheet.

A widely used convention marks input cells — the ones a person types into — in one distinct color, and leaves calculated cells unshaded. Anyone opening the workbook then knows immediately which cells are safe to change and which contain formulas they would break.

Fill color changes the background color of selected cells.


## Applying Borders

## Using Cell Styles
Excel provides built-in cell styles for quick formatting.


## Horizontal Alignment
Horizontal alignment positions text left, center, or right within a cell.


## Vertical Alignment
Vertical alignment positions text at the top, middle, or bottom of a cell.


## Knowledge Check
Check yourself: Which formatting option applies color to the background of a cell? Answer: Fill Color. Fill Color sets the background of the cell. Font Color changes the text itself, and Border Color affects only the cell's outline.
