## Before you build the quicklinks — three things to confirm

1. **Dropbox names.** The dropbox titles printed on each Write It page are the *expected*
   Brightspace names, listed above. If any differ in the live shell, edit
   `lib/content/eng0300/writing/writeItTasks.ts` so the on-screen instruction matches what
   the student actually sees. Weeks 1 and 2 predate the `WRITE IT!` sub-modules, so their
   backfilled tasks point at the portfolio collection rather than a weekly dropbox.

2. **The Brightspace URL is not set.** `lib/content/eng0300/writing/brightspace.ts` is
   deliberately empty, so every "Back to Brightspace" affordance renders as instruction
   rather than a link. Paste the course home URL there to turn them all into working links
   at once. No plausible-looking URL was invented.

3. **Bank size.** The Sentence Skills engine reads a JSON bank that currently holds
   **90 original items**, not the 572 referenced in the build request — no
   572-question grammar bank exists anywhere in this repository. The engine, schema, and
   validator are built for any size; adding items is a JSON edit with no code change. See
   `lib/content/eng0300/writing/sentence-skills/README.md`.
