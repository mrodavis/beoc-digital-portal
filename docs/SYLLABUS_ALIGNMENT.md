# OAP Syllabus Alignment

Source syllabi (extracted to plain text in `docs/syllabi/`) were provided from
`~/Desktop/OAP Syllabi`. This file records how each SUNY BEOC course maps to a
course in this portal, and which syllabus modules were missing from the portal
before alignment.

| Syllabus | Course code | Portal course |
|---|---|---|
| Office Productivity Applications | INFO 3033 | `office-assistant/office-apps` |
| Technology for the Workplace | INFO 3023 | `office-assistant/tech-foundations` |
| Database Management | BUSI 3034 | `office-assistant/intro-database` |
| Cloud Technology with AI | INFO 3035 | `office-assistant/modern-office` |

`office-assistant/modern-office` is the Cloud Technology with AI course. Its
route already carried that title; the syllabus foundations (computer basics,
cloud service models, Windows and file management, networking) and the AI
foundations were missing and have been added as modules 1-7, ahead of the
existing office-operations modules, which are now 8-15.

## INFO 3033 — Office Productivity Applications

Syllabus modules, sessions 2-30:

1. **Foundations** — hardware; software; OS and file management (sessions 2-7)
2. **Word processing** — MS Word / **Google Docs** (sessions 8-14)
3. **Presentation** — MS PowerPoint / **Google Slides** (sessions 17-19)
4. **Spreadsheet** — MS Excel / **Google Sheets** (sessions 20-25)
5. **Database applications** — **MS Access** (sessions 27-28)
   5-Alt. **Word-Excel integration** — mail merge (sessions 27-28)

Gaps closed during alignment: the Google Workspace half of modules 2-4, which
the syllabus pairs with every Microsoft application, and the MS Access module.

## INFO 3023 — Technology for the Workplace

1. **Foundations** — hardware (3-4); software and file management (5-6)
2. **New technology** — history and evolution of the internet and devices (8-10)
3. **Device security** — securing personal and work devices (12)
4. **Applications — Internet of Things** — app development principles, apps vs.
   OEM software, designing a simple SOHO network (13-14)

Gaps closed: modules 2 and 4, which had no counterpart in the portal.

## BUSI 3034 — Database Management

1. Introduction to databases and Microsoft Access (2-3)
2. Working with tables (4-5)
3. Data entry and forms design (6-7)
4. **Querying data — SQL statements** (8-9)
5. **Advanced queries and reports** — crosstab, action, append (10-11)
6. **Data analysis and automation — macros and VBA** (12-14)

Gaps closed: SQL, advanced query types, and the macros/VBA automation module.

## INFO 3035 — Cloud Technology with AI

Topics from the SP25 course outline. The AI half is current to the course as
taught and is not in the SP25 document:

- Computer basics; build a virtual computer
- Cloud computing basics — IaaS, PaaS, SaaS
- Windows navigation and File Explorer
- SaaS in action — Google cloud-based applications
- Document creation and sharing
- The internet and networking — LAN vs. WAN
- AI foundations — what AI, ML, and LLMs are, and AI as a cloud service
- Working with AI — prompting, and verifying output before relying on it

Gaps closed: modules 1-7 of `modern-office`. The pre-existing modules (now 8-15)
cover applied office operations and were retained.
