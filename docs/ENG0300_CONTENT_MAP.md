# ENG0300 Content Map

Maps each syllabus course outcome to its source material, week, skill lab, practice material, and a possible assessment.

**Reading rule for the "Source Material" column:** these entries record which commercial materials *cover* the outcome and which pages the syllabus assigns as homework. They are **references, not hosted content**. Nothing from these workbooks is reproduced in the portal. See [`ENG0300_SOURCE_AUDIT.md`](./ENG0300_SOURCE_AUDIT.md).

**Assessment column:** every entry is a *possible* assessment for the instructor to build. Official, graded assessment lives in Brightspace and is administered by the instructor. Nothing in this column is implemented as a graded instrument in the portal.
