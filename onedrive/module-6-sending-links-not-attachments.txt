Sending Files as Links Instead of Attachments

Module 6: OneDrive with Teams, Outlook, and Office

Send coworkers a link to the one real file instead of an attached copy, choose what the link allows, and know when a copy (or a secure method) is the right call.

By the end of this lesson you can:
- Explain why a link beats an attachment for files people work on

## Sending a link
- From OneDrive: select the file › Share, add people, choose the permission, type a message, and select Invite. OneDrive emails them a link.
- Or select Copy link, check who the link works for (the gear), select Copy, and paste the link in your email or Teams message.
- In the new Outlook for Windows: in a new message, select Attach file and pick a file from OneDrive (or Suggested files). You choose whether to send a link or a copy. For a link, select the arrow on the attachment to change permissions: Organization can Edit, Organization can View, Recipients can Edit, or Recipients can View. In a business account the default lets everyone in your organization edit, so check it before you send.

Note: The Microsoft Outlook course covers attachments in classic Outlook and Outlook on the web. The idea is the same everywhere: a link shares the one real file, and its permission decides what people can do.


## When a copy is right
Send a copy (often a PDF) when the other person needs a fixed record that shouldn't change, such as a signed form or a final invoice, or when they can't sign in to see a link. And for patient information, follow your office's approved secure method; sometimes that is a link shared with one named person, and sometimes it is a secure messaging or fax system. Never attach patient information to a regular email because it is faster.

## Knowledge Check
Check yourself: You attach a OneDrive file as a link in the new Outlook at work and don't change anything. Who can edit it by default? Answer: Everyone in your organization. In a business account, the default link lets everyone in your organization edit. Change it with the arrow on the attachment if that is too much access.

Check yourself: Why is a link better than an attachment for a report several coworkers update? Answer: Everyone works in the one current file instead of separate copies. A link points everyone to the same file, so there is one current version.
