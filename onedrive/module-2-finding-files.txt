## Favorites and shortcuts
In a work or school OneDrive, Add to favorites (right-click a file, or select More actions) puts a file in the Favorites view. Favorites doesn't move or copy the file; it is a bookmark. Remove from favorites takes the bookmark away.

Files shared with you stay in their owner's OneDrive, so they are not in your My files. For a shared folder you use every day, select it in Shared and choose Add shortcut to My files. The shortcut appears in My files (and in File Explorer, if you use the sync app), but the folder still belongs to its owner, and their sharing still decides what you can do. Shortcuts work for folders, not single files. To remove one, select it in My files and choose Remove shortcut from My files; that doesn't affect the owner's folder.

Practice: Drag each job onto the OneDrive tool that does it.

Note: Search looks through your OneDrive and the files shared with you. If you get too many results, add another word from the file's name.


## Knowledge Check
Check yourself: Maria shared the Front Desk Procedures folder with you, and you want it in My files. What happens when you select Add shortcut to My files? Answer: A shortcut to Maria's folder appears in My files; the folder stays hers. A shortcut points to the shared folder. It still lives in Maria's OneDrive and her sharing settings still apply.

Check yourself: You remove a file from Favorites. What happens to the file? Answer: Nothing; only the bookmark is removed. Favorites is a list of bookmarks. Removing a favorite leaves the file exactly where it was.
