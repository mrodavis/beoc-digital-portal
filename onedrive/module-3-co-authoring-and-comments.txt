Co-authoring and Comments

Module 3: Sharing and Collaboration

Edit a document at the same time as your coworkers, see who is working where, and use comments, @mentions, and Reviewing mode instead of email back-and-forth.

By the end of this lesson you can:
- Open a shared document in Word for the web and recognize co-authors' presence
- Add a comment to a paragraph and @mention a coworker
- Reply to and resolve comment threads
- Switch between Editing, Reviewing, and Viewing modes


## One file, many editors
 type: scenario
 role: You are updating the Check-In Procedures with the front desk team.
 text: In the past, updating the procedures meant emailing a document around, collecting three edited copies, and spending an afternoon combining them. Now the document is in OneDrive, shared with the team. Maria is editing the insurance section right now, Kevin left a question in a comment, and Tasha finished her part.
 task: Work in the same document at the same time, answer comments, and pull Maria into a question without leaving the file.

When a Word, Excel, or PowerPoint file is in OneDrive and shared with edit permission, several people can work in it at the same time. This is co-authoring. Each person's changes show up for the others within moments, and colored flags show who is working where. Word for the web saves as you type, so nobody needs to save and send a new copy.

 type: key-terms
 terms:
   term: Co-authoring
   definition: Several people editing the same file at the same time.
   term: Presence
   definition: The pictures at the top and the colored flags in the document that show who is in the file and where.
   term: Comment
   definition: A note attached to a paragraph, outside the text, that people can reply to.
   term: @mention
   definition: Typing @ and a name in a comment, so that person gets a notification.
   term: Resolve
   definition: Marking a comment thread as done. It stays in the document's history but leaves the active list.


## Comments and @mentions
1. Click in the paragraph you want to comment on.
2. Select Review › New comment (or right-click the paragraph and select New comment).
3. Type your comment. To get someone's attention, type @ and the first letters of their name, then pick them from the list.
4. Post the comment. A mentioned coworker gets a notification with a link to the comment.
5. To answer a comment, type in its Reply box. When the question is settled, open the thread's More thread actions (…) and select Resolve thread.

Comment instead of rewriting someone else's section. A comment asks; an edit decides. For changes you want the owner to approve, switch to Reviewing mode so your edits show as suggestions they can accept or reject.

Practice: Put these steps in the order they happen.


## Editing, Reviewing, and Viewing
 type: table
 caption: Modes in Word for the web (the mode button near the top right)
 columns:
   Mode
   What it does
   Use it when
 rows:
    Editing
    Your changes go straight into the document
    It is your section, or you were asked to edit
    Reviewing
    Your changes show as suggestions others can accept or reject
    You are suggesting changes to someone else's work
    Viewing
    You can read the document but not change the text
    You only want to read without changing anything by accident

Note: Version history (Module 4) keeps earlier versions of shared files, so a co-author's mistake can be undone. Co-authors should still agree on who edits which section.


## Knowledge Check
Check yourself: You want Maria to answer a question about the insurance section without leaving the document. What is the best way? Answer: Add a comment on that paragraph and @mention Maria. An @mention in a comment notifies Maria and keeps the question attached to the exact paragraph.

Check yourself: You want to suggest wording changes to Kevin's section without changing it directly. Which mode do you use? Answer: Reviewing. Reviewing mode records your edits as suggestions Kevin can accept or reject.
