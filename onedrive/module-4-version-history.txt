Restoring an Earlier Version

Module 4: Keeping Files Safe

Use version history to see earlier versions of a file, check what changed, and restore the right one, from OneDrive on the web or from inside Word.

By the end of this lesson you can:
- Open version history from OneDrive on the web and from a Word document
- Open an earlier version to check it before restoring
- Restore an earlier version and explain what happens to the current one
- Explain how long versions are kept in personal and work or school accounts


## Someone typed over the schedule
 type: scenario
 role: You keep the staff schedule up to date at Lakeside.
 text: At 9:05 this morning, Kevin pasted October's shifts over the November staff schedule by mistake and saved. Half the office is looking at the wrong shifts. Nobody made a backup copy, and nobody needs to: OneDrive kept the earlier versions.
 task: Find yesterday's correct version, check it, and restore it, without losing anything.

Version history is a list of earlier versions of a file that OneDrive keeps as people change it. Each version shows when it was saved and who saved it. You can open an earlier version to read it, and restore it to make it the current version again.

 type: table
 caption: Three ways to open version history
 columns:
   From
   Steps
 rows:
    OneDrive on the web
    Right-click the file (or select it and select More actions …) › Version history
    File Explorer (with the sync app)
    Right-click the file in your OneDrive folder › Version history
    Word, Excel, or PowerPoint (desktop)
    Select the file name in the title bar › Version History, or File › Info › Version History


## Check, then restore
 type: worked-example
 title: Restoring yesterday's staff schedule
 task: Put back the version of Staff Schedule - November.xlsx that Maria saved yesterday afternoon.
 steps:
   move: Right-click Staff Schedule - November.xlsx and select Version history.
   why: The Version history panel lists every saved version with the date, time, and person.
   move: Find the version Maria saved yesterday, before Kevin's change this morning.
   why: The Modified and Modified by columns tell you which version is the last good one.
   move: Open that version and read it before you restore it.
   why: Opening it first lets you confirm it really has the November shifts. Restoring the wrong version just creates a new problem.
   move: Select the ellipses (…) next to that version and select Restore.
   why: Restore makes that version the current version again. Kevin's version stays in the list, so nothing is lost.
   move: Tell the team the schedule is fixed.
   why: People who opened the wrong shifts need to know to look again.
 result: The current version is November's schedule again, and Kevin's version is still in the history if anyone needs it.
 takeaway: Open it, check it, then restore. Restoring never erases the version you are replacing.

Practice: Drag the steps for restoring an earlier version into order.


## How long versions are kept
In a personal OneDrive, Microsoft keeps file version history for 30 days. In a work or school OneDrive, your organization's settings decide how many earlier versions are kept, and administrators can turn versioning off. Version history only helps with files that are in OneDrive, which is one more reason to save work files there instead of on the desktop.

Note: Version history fixes changes inside one file. If many files were changed at once, for example by ransomware, Restore your OneDrive (later in this module) can roll back your whole OneDrive.


## Knowledge Check
Check yourself: You restore version 4.0 of a file whose current version is 5.0. What happens to version 5.0? Answer: It stays in version history; the restored copy becomes the new current version. Restoring makes a copy of the older version the new current version. The version you replaced stays in the history.

Check yourself: Why open an earlier version before restoring it? Answer: To confirm it is the right version, so you don't replace one mistake with another. Checking first makes sure you restore the version you actually want.
